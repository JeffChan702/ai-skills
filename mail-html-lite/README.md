# mail-html-lite · 轻量邮件 HTML

## 它解决什么

发邮件时正文通常两种下场：要么全挤在一起、标题糊成一团；要么为了好看塞进一堆 CSS 框架和渐变卡片，结果到了邮件客户端（Outlook / Gmail / 企业微信）全乱掉。

这个 skill 只干一件事：**给你一个 720px 宽的干净外壳**，段落不挤、标题分得清，复制粘贴就能用。它不写脚本，是一个纯排版约定。

## 什么时候用它

- 你已经写好正文，需要一个统一、稳定的外壳
- 现有 HTML 段落挤在一起、标题糊成一团
- 要在邮件里放表格或代码块

## 怎么装

把 `mail-html-lite/SKILL.md` 复制到你的 skills 目录：

| 你在用的工具 | 目标路径 |
|---|---|
| Cursor | `~/.cursor/skills/mail-html-lite/SKILL.md` |
| Claude Code | `~/.claude/skills/mail-html-lite/SKILL.md` |
| WorkBuddy | `~/.workbuddy/skills/mail-html-lite/SKILL.md` |

不需要装依赖。这个 skill 里没有脚本，就是一份排版约定加一个可直接套的 HTML 壳。

## 怎么简单测试（30 秒）

重启工具，发这句：

```
用 mail-html-lite 把这封邮件排一下版：

标题：周三发版通知
内容：
1. 本次改动 3 个
2. 需要回归的模块是订单和库存
3. 有问题找我
```

**通过标准** —— 它给你的 HTML 应该满足：

- 最外层 `div` 是 `max-width:720px`
- 每个大节有自己的 `<h3>`，节与节不粘连
- **没有** `<style>` 标签、没有引入 CSS 框架、没有渐变色
- 内容一个字没被改写

把那坨 HTML 存成 `.html` 用浏览器打开，或者直接粘进邮件客户端，看段落有没有粘在一起。

## 设计取舍（为什么故意这么简单）

| 选择 | 原因 |
|---|---|
| 只用内联样式 | 邮件客户端对 `<style>` 和外部 CSS 的支持极不一致，内联最稳 |
| 宽度 720px | 桌面端舒适、手机端不至于横向滚动 |
| 不写脚本 | 这是排版约定，不是生成器；多加一层生成器就多一层出错的地方 |
| 不碰内容 | 排版和改内容是两件事，混在一起两边都做不好 |

## 边界

- 它**不改写**你的内容语义。正文里有黑话要改，那得回去改正文，不是靠排版掩盖。
- 它**不做视觉设计**。想要花哨效果的，这个 skill 明确不是给你的（见 SKILL.md 末尾的「禁止」）。
